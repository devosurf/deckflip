# Measured font selection and Office identity are distinct

The invariant from #15 remains: the selected face used for measurement must be the face addressed by the PPTX. [#32](https://github.com/devosurf/deckflip/issues/32), under [#30](https://github.com/devosurf/deckflip/issues/30), supersedes the original decision to serialize one preferred family name with CSS-derived bold/italic.

A Resolved font separates CSS font aliases, the selected asset and member face, and Office font identity. The legacy family/subfamily (name IDs 1/2), checked against consistent style metadata, determine Office family/RIBBI. Preferred names remain matching aliases. Numeric CSS weights remain authored browser inputs, never Office style-linking rules. Missing, contradictory or unsupported identity fails explicitly; do not strip font tables or remap weights.

Generic families remain rejected when reached before a concrete match: Chromium resolves them to different faces across operating systems, so accepting them would make measurement and conversion machine-dependent. An unresolved concrete stack also fails validation. The default is not appended to authored stacks and never masks a missing family.

[#35](https://github.com/devosurf/deckflip/issues/35) supersedes the transitional injected `body { font-family: Arial }` with bundled Liberation Sans 2.1.5 static Regular, Bold, Italic and BoldItalic faces. A root declaration in the first anonymous cascade layer lets authored root, body, Slide and text families win, including authored layers; there is no body default. Bundling trades host-dependent measurement for redistributable, manifest-pinned bytes, served and hash-checked by `FontSources` through `DeckFontSession`, the same path used for Deck font assets. Resolved-font provenance is `source: { kind: 'bundled', family: 'Liberation Sans', version: '2.1.5', file: <basename>, format: 'ttf', sha256 }`.

[#34](https://github.com/devosurf/deckflip/issues/34) makes `@font-face` the pinned-asset path. deckflip answers every stylesheet and font request Chromium makes, drops `local()` sources and serves each `url()` as the decoded sfnt that identifies the asset, so the face Chromium measures is the selected face on any machine. A declared family matches only its rules. Downloads are frozen once in the Asset directory and never refreshed, trading freshness for repeatable measurement and offline conversion. Chromium's per-node platform-font record audits fallback; it names fonts, not files, so it is evidence, not identity. Installed-font discovery still serves explicit families not supplied by Deck or bundled assets.

The bundled default remains a non-safe, `deck-provided` Resolved font and reports `FONT_NOT_SAFE`: reproducible authoring is not recipient portability. Embedding and the portable-default cutover remain deferred to [#36](https://github.com/devosurf/deckflip/issues/36). The strict template already explicitly authors Arial on `body`, so it does not select the bundled default. PPTX-to-HTML output emits explicit source families and no bundled default.

Structural Verification does not establish font fidelity or identical per-glyph fallback. Package inspection and supported-PowerPoint edit/save/reopen evidence are separate requirements; affected Oracle records require actual PowerPoint runs ([ADR 0007](0007-verification-and-powerpoint-oracle.md)).
