# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `devosurf/deckflip`.
Use the `gh` CLI. Run inside this clone or pass `--repo devosurf/deckflip`.

## Issue operations

- Create: `gh issue create --title "..." --body-file <file>`.
- Read: `gh issue view <number> --json number,title,body,comments,labels,author,createdAt,updatedAt,state,url`.
- List: `gh issue list --state open --json number,title,body,labels,comments,createdAt,updatedAt`.
  Select the state and label filters appropriate to the task.
- Comment: `gh issue comment <number> --body-file <file>`.
- Label: `gh issue edit <number> --add-label "..." --remove-label "..."`.
- Close: `gh issue close <number>` after posting the outcome.
- "Publish to the issue tracker" means create a GitHub issue.
- "Fetch the relevant ticket" means read its body, comments, and labels.

Every issue body or comment posted during triage must start with:

> *This was generated by AI during triage.*

Use [triage-labels.md](triage-labels.md) for category and state mappings.

## Pull requests as a triage surface

**PRs as a request surface: no.**

An explicitly named PR can still be triaged. GitHub shares issue and PR numbers;
resolve a bare number with `gh pr view <number>`, falling back to
`gh issue view <number>` when it is not a PR. Read PR discussion and
`gh pr diff <number>` before assessing attached code.

If the flag is changed to `yes`, discover external PRs whose author association
is `CONTRIBUTOR`, `FIRST_TIME_CONTRIBUTOR`, or `NONE`. Exclude
`OWNER`, `MEMBER`, and `COLLABORATOR` from discovery only.

## Wayfinding and dependencies

- Keep maps under `wayfinder:map` and decision tickets under the existing
  `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, and
  `wayfinder:task` labels.
- Link child tickets as GitHub sub-issues. If unavailable, use a task list
  on the map and a `Part of #<map>` reference on each child.
- Record blocking edges with GitHub native issue dependencies:
  `gh api --method POST repos/devosurf/deckflip/issues/<child>/dependencies/blocked_by -F issue_id=<blocker-database-id>`.
- Obtain the database ID with
  `gh api repos/devosurf/deckflip/issues/<blocker> --jq .id`;
  it is not the issue number or node ID.
- If native dependencies are unavailable, use a `Blocked by: #<number>` list
  in the issue body. A ticket is unblocked when every blocker is closed.
- Select unassigned, open children with no open blockers, in map order.
  Claim with `gh issue edit <number> --add-assignee @me`.
- Resolve by posting the decision, closing the ticket, and linking the
  decision from the map.
