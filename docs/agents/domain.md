# Domain docs

This project uses one domain context.

## Before exploring

Read [CONTEXT.md](../../CONTEXT.md) for the domain glossary and the relevant
decisions under [docs/adr/](../adr/).

If a referenced domain document is absent, proceed without creating a
placeholder. Domain modeling records terms and decisions when they are resolved.

## Vocabulary

Use the glossary's terms in issue titles, briefs, hypotheses, and test names.
If a needed concept is missing, reconsider the wording or flag the gap for
domain modeling.

## Decisions

Surface conflicts with existing ADRs explicitly. Name the conflicting
decision and explain why it should be reconsidered rather than silently
overriding it.
